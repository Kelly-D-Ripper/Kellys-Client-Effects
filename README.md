# Client Effects & Weather

Apparently Nuclear Option wasn't wet or noisy enough.

Weather, cockpit sounds, ocean effects, lights, trails and other shiny distractions. **Pre-release:** if it catches fire, tell us which bit.

## Install

Install BepInEx, then extract the client ZIP into your Nuclear Option folder. Use one copy of the pack. Open **FX** on the map MFD, or use **Ctrl + F8** for the effects panel. Weather controls are single-player only.

The DOORMAN card is included. The optional DOORMAN preview groups the pack into one entry.

Want volumetric clouds? Get [NOAtmoFX](https://github.com/paulleonard1314-lang/NoAtmoFX/releases) separately. The game will survive without it.
