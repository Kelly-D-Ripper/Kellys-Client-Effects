# Source notes

This repository contains the adapted client component sources and the recovered canopy rain shader sources. Building requires a separately installed copy of Nuclear Option and BepInEx; game assemblies are not included. The Better Night binary in the release is an adapted component and its complete build source is not yet assembled in this repository. NOAtmoFX is a separate optional project and is not redistributed here.

The rain shader and accompanying masks were recovered from Boscali Summer commit c00971bbc9bc976fb5458f5cc7d20dcf0493740d. The serialized CanopyRain and CanopyDroplets shader objects in that commit's weather bundle are byte-identical to the objects in the bundle from d11a507424439f8d84c089afa681bcf86aacb44c used by this release. Third-party notices are included in the client ZIP and under third-party.

The v0.8.1 Git tag records the initial build. The client ZIP on the updated v0.8.1 pre-release includes the newer five-light approach rows; its matching source is available in the release's separately named source ZIP and on current main. GitHub's automatically generated source archives still correspond to the original tag.

Version 0.8.2 combines the runway-grounding candidate and the optional NOAtmoFX 1.4 bridge. Startup/ contains the client-only early loader helper; install its DLL under BepInEx/patchers. NOAtmoFX remains a separate download. See VALIDATION-0.8.2.md for the checks and remaining limits.

Version 0.8.3 builds one discoverable plugin from Weather/BoscaliUnifiedWeather.csproj. Payloads/ contains the eight pinned private modules embedded by that project; PayloadTools/ records the narrowly scoped registry and embedded-bundle adaptations from the verified 0.8.2 client ZIP. It does not merge type namespaces or redistribute NOAtmoFX. The separate Startup/ helper is unchanged. Existing component projects remain available as the original adapted sources. Configuration file identities are preserved.

Version 0.8.4 is a local candidate on codex/client-effects-0.8.4. Build-Candidate.ps1 rebuilds Krop, MissileBoom and Controls, prepares their private-registry payloads alongside the pinned unchanged modules, and embeds them in Weather. Building requires the locally retained, hash-pinned 0.8.2 client ZIP and the tested helper in Startup/Pinned. Startup/ contains that helper's matching source; version 0.8.3.1 protects the owner host even without optional mods. Packaging also requires the pinned 0.8.3 ZIP to retain its original inline notices. These scripts do not download, install or publish anything. Package-Candidate.py seals only exact passing isolated test bytes. See VALIDATION-0.8.4.md for the runtime checks and remaining acceptance limits.
